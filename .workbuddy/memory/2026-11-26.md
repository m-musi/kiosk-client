## 修复：主窗口先在左上角出现再跳到中间
- 根因：tauri.conf.json 的 main 窗口未配置 center，窗口创建时落在默认位置（左上角），setup 里 guide.center() 再移到工作区中心 → 闪跳。
- 修复：窗口配置加 "center": true，创建时即居中（按工作区居中，垂直方向比物理屏中心偏上约 20px 属正常，任务栏 40px）；setup 的 center() 保留为兜底 no-op。
- 实测：窗口中心 (960,520) = 工作区中心（1920x1040），首帧即在中心。

## Win7 兼容性评估（咨询，未改代码）
- 硬约束：WebView2 Runtime 封顶 109（微软 2023-01 停止 Win7 支持，109+ Fixed Version 在 Win7 启动失败，Evergreen 在 Win7 自动装 109）；Rust 1.78+ MSVC 最低 Win10，本项目 tauri 2.12 要求 rustc 1.90（本机 1.99），编译产物无法跑 Win7。
- 结论：可行但需 Win7 专供分支——锁 Rust 1.77.x + Tauri 2.0.x + 插件旧版；本项目 Win32 API 全为老 API 兼容；考试网页必须兼容 Chromium 109。
- 建议路线：主线不动，早期 tag 拉 win7-support 分支冻结维护；或优先评估 Win7 设备升级 Win10。
